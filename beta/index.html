📖 이용 방법 및 법규 안내
웹 사용 방법
01
기본 설정 입력
기관 구분(민간/공공), 건물 용도, 기후대, 연면적을 선택·입력하면 목표 점수와 의무항목이 자동으로 결정됩니다.
02
적용 항목 체크
단열·외피 / 기계설비 / 전기설비 / 신재생에너지 탭에서 설계에 반영된 항목을 클릭하여 체크합니다. 황색 테두리 항목은 의무 적용 대상입니다.
03
좌측 점수 패널 확인
EPI 총점·분야별 점수가 실시간 산정됩니다. 목표점 마커(황색)와 현재 점수를 비교하고, 의무항목 현황 패널에서 미충족 항목을 확인하세요.
04
프로젝트 정보 입력
공사명·작성자·작성일을 입력합니다. A4 인쇄 보고서에 자동 반영됩니다.
05
A4 미리보기 · 인쇄
상단 탭 [A4 미리보기·인쇄]를 클릭하면 EPI 검토서 전체를 미리보기 후 인쇄할 수 있습니다. 각 분야 테이블은 페이지 중간에서 잘리지 않습니다.
06
열관류율 검토 연동
헤더의 [열관류율 검토 ↗] 버튼으로 열관류율 종합 검토 시스템을 새 창에서 연결하여 U값을 계산할 수 있습니다.
