## GitHub Pages 배포 방법

1. 이 폴더의 **모든 파일**을 GitHub 저장소 루트에 업로드하세요.
2. Settings → Pages → Branch: `main`, folder: `/ (root)` 설정 후 Save.
3. 배포된 URL (예: `https://username.github.io/repo/`)에서 접속하면 설치 버튼이 활성화됩니다.
